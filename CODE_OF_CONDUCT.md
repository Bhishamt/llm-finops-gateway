# Code of Conduct

## Our commitment

We want llm-finops-gateway to be a project where anyone can contribute regardless of background,
experience level, identity or employer. Maintainers and contributors commit to a respectful,
harassment-free experience for everyone.

## Expected behaviour

- Be respectful and constructive. Critique code and ideas, not people.
- Assume good faith. Ask before judging.
- Give credit, accept feedback, admit mistakes.
- Keep discussions on topic and in public channels where possible so others can learn.
- Respect the maintainers' time: read the docs, search existing issues, fill in templates.

## Unacceptable behaviour

- Harassment, intimidation, discrimination or personal attacks in any form.
- Sexualised language or imagery, unwelcome attention.
- Publishing others' private information without consent.
- Trolling, sustained disruption of discussions, or deliberately derailing reviews.
- Any conduct that would be inappropriate in a professional setting.

## Scope

This code applies in all project spaces (repository, issues, pull requests, discussions,
chat) and when representing the project in public, for example at meetups or in talks.

## Reporting

Report violations privately to the maintainers listed in [MAINTAINERS.md](MAINTAINERS.md), or to
the project lead at the contact address in [SECURITY.md](SECURITY.md). Reports are handled
confidentially. The reporter will receive an acknowledgement within 5 working days.

## Enforcement

Maintainers may take any action they judge appropriate, including:

1. a private warning;
2. a public warning and request to stop;
3. temporary exclusion from project spaces;
4. permanent ban.

Maintainers who do not follow or enforce this code in good faith may be removed by vote of the
other maintainers as described in [GOVERNANCE.md](GOVERNANCE.md).
